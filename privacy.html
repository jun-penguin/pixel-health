プライバシーポリシー / Privacy Policy

最終更新: 2026-10-06

読み取るデータ

作成者本人の Google アカウントにある、健康データ（Google Health API：睡眠・歩数・安静時心拍・運動）と Google ToDo（Google Tasks API）を、読み取りだけで使います。書き換えや削除はしません。

使い方と保存場所

読み取ったデータは、作成者本人のパソコン、本人のメモ、本人だけが入っている Discord サーバーへの通知にだけ使います。第三者に売ったり、渡したり、広告に使ったりはしません。

利用者

このツールの利用者は作成者本人だけです。

English

This tool reads only the creator's own Google Health API data (sleep, steps, resting heart rate, exercise) and Google Tasks, read-only. The data is used only on the creator's own computers, in the creator's own notes, and in notifications to a Discord server that only the creator belongs to. It is never sold, shared with third parties, or used for advertising. The only user of this tool is the creator.
